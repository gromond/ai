# Gromond AI — Landing Page

A modern AI company landing page inspired by leading AI products (Claude, ChatGPT, Kimi) — clean hero, live chat demo, features, models, pricing and FAQ.

## Run it

Just open `index.html` in a browser — no build step needed.

Or serve it locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Files

- `index.html` — the complete landing page (HTML + CSS + JS in one file)
